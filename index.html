Tansolution — 기업용 탄소회계 SaaS 플랫폼

기업의 온실가스 배출량을 산정·관리·보고하는 B2B SaaS. 기획 단계부터 참여.

기간 기획 2022.12 – 2023.04 · 개발 2023.04 – 2026.05 역할 프론트엔드(고객사 담당자용 웹) + 서버 일부 기여 3,883 커밋 · 9명 중 2위

주요 작업

  • 초기 기획 참여 — 개발 착수 전(2022.12~2023.04) 기능정의서, 회원가입 프로세스 레이아웃, 기능명세서, DB 모델링 등 기획 산출물 작성에 참여
  • 배출량 관리 핵심 화면 — 배출원 등록 폼(EmissionCreateForm), 배출량 목록(EmissionList), 조건별 필터링. 대량 입력 상황을 위해 무한 스크롤과 제출 큐(submit queue)를 도입해 연속 저장 시 유실·중복 방지
  • 대시보드·데이터 시각화 — 연도별·기간별 배출량, 지분율 반영 계산(equity ratio), Scope 2·3 범례 구성에 더해 MACC(한계저감비용) 차트, SBTi 감축목표 대시보드, 감축 시나리오 시뮬레이션 대시보드, 누적 배출 StackERChart 등 도메인 특화 차트 구현. 차트–테이블 하이라이트 연동, 호버·클릭 인터랙션, 스켈레톤 로딩으로 탐색형 대시보드 구성
  • OCR 증빙 문서 처리 UI — 고객사 담당자가 월 수십 건의 배출량 데이터를 증빙 문서와 대조해 수기 입력하던 작업을 OCR 인식 + 검증 방식으로 전환. 썸네일 자동 줌(ZoomableThumbnail)과 페이지 인덱스 연동으로 검토 중인 항목 위치를 자동 표시하여, 입력 작업을 확인 작업으로 축소
  • 보고서 시스템 — 기본 배출량 보고서(BasicReport / BasicNewReport)를 중심으로 사회 부문(SocialSectorReport), 안전보건(SafetyHealthReport), 건설(ConstructionReport), 에너지, SBTi, 첨부 증빙(AttachedDocReport) 등 보고서 유형 다수 개발. 인쇄 전용 레이아웃(Print 컴포넌트)으로 PDF 출력까지 지원하고 국문·영문 양쪽 대응
  • 제품 영문화(i18n) — 해외 고객 대응을 위해 2024.12부터 제품 전반의 영문 버전 구축. 언어 전환 도입 후 로그인·배출량 등록·Scope 상세 모달 등 주요 화면과 기본 보고서·시뮬레이션 대시보드, 관리자 초대·계정 생성·MFA 이메일 템플릿까지 영문 대응. 배출계수 목록은 한글·영문 우선순위를 반영한 커스텀 정렬로 처리
  • 협력사·조직 관리 — Scope 3(공급망) 배출량 수집을 위한 협력사 관리 기능. 법인등록번호·사업자등록번호 유효성 검사를 포함한 협력사 등록 폼(PartnerCompanyInfoForm), 협력사 데이터 요청 시트와 요청 메일 분기 처리, 조직 계층을 다루는 트리 테이블(OrganizationTable·CustomTreeItem) 개발
  • 인증·보안 — 이메일 기반 다중 인증(MFA) 구현: 토큰 발급·검증 쿼리(createMFAToken / validateMFAToken)와 입력 폼, 시도 횟수 제한, 만료 토큰 처리 및 404 분기. MFA·계정 생성·협력사 요청 메일 템플릿을 국문·영문으로 대응
  • 성능·안정성 — 배출량 목록 무한 스크롤, 라우트 단위 lazy loading과 청크 로드 실패 시 재시도(retryLazy), 연료 단위 변경의 낙관적 업데이트, ErrorBoundary 도입
  • 대기업 고객 대응 — 삼성·DRB 등 고객사별 요구사항 반영 및 커스터마이징 (커밋 이력 기준)
  • 서버 사이드 — server/src(TypeScript) 수정 다수, API와 화면을 오가며 기능 단위로 완결성 있게 개발. 모노레포 구조로의 서버 리팩터링 참여
