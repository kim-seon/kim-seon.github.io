# 김선 — 이력서 · 기술경력서 · 포트폴리오

프론트엔드 개발자 김선의 지원 서류입니다. 한 페이지에서 세 문서를 탭으로 전환하며 볼 수 있고, 각 탭을 개별 PDF로 저장할 수 있습니다.

**👉 [전체 보기](https://kim-seon.github.io)** — 탭으로 세 문서 전환

## 구성

문서별 링크로도 바로 열 수 있습니다.

| 문서 | 내용 | 링크 |
|---|---|---|
| 이력서 | 인적 사항 · 경력 요약 · 기술 스택 | [resume](https://kim-seon.github.io/resume.html) |
| 기술경력서 | 프로젝트 7건의 상세 작업 내역과 기여도 | [career](https://kim-seon.github.io/career.html) |
| 포트폴리오 | 대표 프로젝트 스토리와 일하는 방식 | [portfolio](https://kim-seon.github.io/portfolio.html) |

## 기술

의존성 없는 정적 HTML입니다. 웹폰트(Pretendard, Noto Serif KR) 외에 외부 리소스를 사용하지 않으며, `@media print`로 선택한 탭만 인쇄됩니다.
